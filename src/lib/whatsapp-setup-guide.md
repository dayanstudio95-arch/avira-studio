# 📱 מדריך חיבור וואטסאפ לאוטומציה

## צעדים להגדרה:

### 1️⃣ בחר שירות וואטסאפ Gateway
בחר אחד מהשירותים הבאים (כולם עבדו עם המערכת):

| שם | עלות | סוג |
|---|---|---|
| **Baileys** (מומלץ - חינם) | ₪0/חודש | Self-hosted / וואטסאפ Web |
| **Twilio** | $0.0075/SMS | API רשמי |
| **WhatsApp Cloud API** | Free tier | API רשמי של מטא |
| **Evolution API** | $29/חודש | Self-hosted ו-Cloud |
| **Wuzapi** | ₪99/חודש | SaaS ישראלי |
| **Green API** | מתחיל ב-$10 | API רוסי אבל בעבודה |

---

### 2️⃣ דוגמה: התקנה עם Evolution API (מומלץ ביותר)

#### א. הירשם ב-Evolution API
1. כנס ל: https://evolution-api.com
2. בחר "Self-hosted" או "Cloud"
3. יצור חשבון וקבל:
   - **Gateway URL**: `https://your-instance.evolution-api.com`
   - **API Key**: `12345-abcde-...`
   - **Instance ID**: `my-instance-1` (כשמי)

#### ב. חבר בהגדרות מערכת
1. עבור להגדרות (⚙️) → **אינטגרציות**
2. גלול ל-"WhatsApp Gateway"
3. הזן:
   - **Gateway URL**: `https://your-instance.evolution-api.com` (ללא slash בסוף)
   - **API Key**: `12345-abcde-...`
   - **Instance ID**: `my-instance-1` (אופציוני, אבל מומלץ)

#### ג. לחץ "חבר QR"
1. סרוק את ה-QR Code עם WhatsApp על הטלפון
2. בחר "קישור מכשיר" / "Link Device"
3. המערכת תכניס את המכשיר שלך כ-"Bot"

---

### 3️⃣ דוגמה: Baileys (חינם אבל צריך infrastructure)

#### א. Setup Baileys Server
```bash
# Clone / הוקם שרת Baileys
git clone https://github.com/whiskeysockets/Baileys
cd Baileys
npm install
```

#### ב. לחבר בהגדרות
- **Gateway URL**: `http://localhost:3000` (אם local)
- או `https://your-baileys-server.com` (אם hosted)
- **API Key**: אתה קובע (כל מחרוזת)

---

### 4️⃣ דוגמה: WhatsApp Cloud API (רשמי ביותר)

#### א. שלוש קובץ ממטא
1. כנס ל-https://developers.facebook.com/
2. צור app → בחר "WhatsApp"
3. אתפסד "Test Access Token" או Production

#### ב. הזן בהגדרות
- **Gateway URL**: `https://graph.instagram.com`
- **API Key**: הטוקן מטא שלך
- שים את זה בשם ה-Instance

## 🤖 הגדרת טריגרים אוטומטיים

### טריגר 1: ליד חדש (סטטוס = חדש)
```
הודעה:
"ברוכים הבאים! 🎉
שמחים שבחרתם בתיאום איתנו.
חבילה מומלצת: {package}
מחיר: ₪{price}
לתשלום המקדמה: {payment_link}"
```
**זה מופעל כשליד נוצר** → מנת"מ מקבל הודעה עם הצעת מחיר.

### טריגר 2: חוזה חתום
```
"מעולה! החוזה חתום ✅
קישור לשאלון הפרטים: {questionnaire_link}
בחרו לנו: {event_details}"
```
**זה מופעל כשמצב הליד → חתום** → הזוג מקבל קישור לשאלון.

### טריגר 3: תזכורת 7 ימים
```
"שלום! 👋
עוד 7 ימים לאירוע המיוחד שלכם! 💍
פרטי הצוות:
{team_details}
יום בחירה: {event_date}
התראות מרכזיות: {contact}"
```
**זה מופעל אוטומטית 7 ימים לפני תאריך האירוע**.

## 🚨 Troubleshooting

### "וואטסאפ מנותק" (סטטוס אדום)
→ סרוק QR Code שוב או בדוק שהטלפון מחובר לאינטרנט.

### "לא ניתן לאחזר QR"
→ בדוק:
  - Gateway URL נכון (ללא slash בסוף)
  - API Key תקין
  - Instance ID בדיוק (אם משתמש)

### "הודעה לא הגיעה"
→ בדוק:
  - מספר הטלפון בפורמט: `972501234567` (ללא +)
  - וואטסאפ מחובר (ירוק)
  - לא בעיה של Gateway (בדוק ב-logs שלך)
